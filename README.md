# d3r1n's notes

> _"Simple. Flexible. Agnostic."_

A simple, flexible, and agnostic hybrid Zettelkasten. This repository is a digital extension of my analog thinking.
You can call it my second brain or a pkm or whatever.

## Philosophy

- Agnostic: Plain Markdown. No proprietary lock-in.
- Simple: Focused on getting actual work done. [(what terry davis said?)](https://www.youtube.com/watch?v=k0qmkQGqpM8)
- Flexible: Connections over rigid hierarchies.
- Hybrid: analog for active thinking, digital for connecting and refining.

## Structure

```
notes/
├── assets/ -> non-note files
├── archive/ -> long-term storage for inactive notes
├── quick/ -> fleeting notes
└── inbox/ -> primary workplace for active notes
```

## Workflow

1. Capture: Ideas begin in physical notebooks.
2. Transcribe: Raw thoughts are moved into quick notes.
3. Synthesize: Notes are refined, and linked in inbox.
4. Produce: Finished pieces are composed in archive for projects, publishing or storage/reference.

## Tooling

- Editor: Zed with vim motions and marksman & Zen notes (Drafting and coding)
- GUI: Zen Notes
- Linting: Markdown file linting done by [markdownlint-cli](https://github.com/igorshubovych/markdownlint-cli)
- Version Control: Git & GitHub (Backup and automation)
- Organization: Flat-folders, filename prefixes, Tags, and Wikilinks
